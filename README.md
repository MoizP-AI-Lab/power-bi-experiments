# Power BI experiments

Measured experiments on Power BI and AI: a question, a test against the rows, and the numbers.
Each folder holds the evidence, the exact queries and code, and a short video or screenshot from Power BI Desktop.
Data: the public Contoso V2 sample from SQLBI (MIT licence) unless a folder says otherwise.

| Experiment | Finding | Tested |
|---|---|---|
| [AI-written DAX on 10M rows](ai/ai-dax-10m) | Two AI drafts counted 57,466 new Audio customers in 2024; the true number is 3,292 | 2026-11-21 |
